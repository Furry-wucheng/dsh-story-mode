# 共用写作流程

本流程供较长新稿、复杂续写或结构改写按需查阅。任务规模决定规划形式；新稿与实质性改写保留独立审读，纯文字小改按 short-story 入口自查。

## 1. 接稿与方向确认

先区分已有要求和真正阻碍交付的缺项。新写、续写时，内容方向或停止位置不清且无法从前文判断，才用 ask_user_question 一次问完；不要给片段附加全篇结局的问题。

作者没有指定字数时可按任务选择合理长度并说明；需要严格控制篇幅时再询问数字或区间。完整作品的微型 3000–5000、短篇 5000–10000、中短篇 10000–20000 仅供参考，片段不设最低字数。

较长或复杂任务可将方向与约束记入 brief.md 或已有记录。作者要求看方案时给简洁人物与节拍安排；请求已清楚或要求直接写时不增加确认轮次。

## 2. 动笔前准备人物卡与节拍

较长新项目可以使用下面四类记录；沿用已有文件名、合并内容或在当前任务中保留简短规划均可：

| 文件 | 必须保留的信息 |
|---|---|
| brief.md | 本次形态、范围、目标字数、内容重点、基调、视角、限制、停止点和确认状态 |
| bible.md | 本次出场的主要人物卡及必要的共享事实 |
| outline.md | 当前篇或片段的节拍顺序、详略、篇幅分配与停止点 |
| draft.md | 正文 |

续写和实质性改稿读取获准的相关人物卡与节拍，沿用有效内容，只补受影响部分。局部措辞修改读取上下文即可；涉及人物状态或故事事实时再核对相关记录。纯景物等没有出场人物的任务不强制人物卡。

### 人物卡

每位主要出场人物至少记录身份、当下动机或需要、关系、性格与说话习惯、当前状态和相关既定事实。需要外形、物种或特殊能力的题材，记录本段会用到的特征和限制；没有依据的事实标待定，不冒充已有设定。人物卡不用扩展成完整生平。

涉及重要关系转折时，人物卡可以补充已知的注意起点或关系由来；正文允许从关系形成之后开始，只有读者理解当前转折确实依赖这段前史时才需要补足线索。

~~~markdown
## 林远（别名：阿远）
- 身份：夜班司机
- 动机：下班后想歇一会儿，今天不急着走
- 关系：林青的哥哥，两人平时互相打趣
- 性格与口吻：对乘客客气简短，和妹妹会絮叨；疲惫时反应慢半拍
- 当前状态：刚结束夜班，有些困
- 相关事实：此段发生在车站候车室，不补写他离开之后的事
~~~

卡片给作者与主代理核对，也供 B2 审读；冷读者 B1 不读卡片。不要把卡片逐项塞进开头，正文只交代理解当前内容所需的信息。story_bible 的字段检查只覆盖身份、动机、关系等工具已有能力，不证明人物塑造或其他卡片内容合格。

### 节拍

节拍描述读者按什么顺序经历当前内容，并非每一拍都必须推进事件。较长任务可记录各拍的主要内容、快慢详略及粗略字数；预算用于分配注意力，无须逐拍凑齐，写到约定停止点即可。

例如一个候车片段可以安排：进入候车室与必要介绍 → 随口聊几句 → 安静坐着看窗外 → 广播响起时停笔。中间的闲聊与停留无需带来关系变化，不必另设冲突或把所有细节变成伏笔。此例不规定拍数或比例，人物和场景也不能直接搬用。

#### 关系与关键转折

较长稿件可在节拍中记下主要变化：谁做了什么、另一方如何回应、读者在此时能看到哪些依据。只记录真正重要的转折，不要求每一拍都有状态改变、代价或均衡的推动者。日常停留和没有后续用途的细节可以独立成场。

涉及感情线时，检查关系变化是否能从正文已有的行动、对话或积累的细节中理解。允许感情含混、起点发生在正文之前，也允许人物不说破；读者不必得到唯一答案。只有关键转折因此显得突然时，再考虑补线索、调整顺序或改变转折幅度，不机械补一场起点戏。

对话可以有闲谈，也可以直接而紧凑。角色看穿他人时，核对其信息来源和既有人物能力；年龄、身份和地位不能单独作为判错依据。
### 方案确认

作者要求方案时，包含人物关系与口吻、节拍安排、篇幅和停止位置。新选择超出此前授权时单独确认；请求已清楚或作者要求直接写时，不增加一轮方案批准。

**方案阶段不派独立读者。** 主代理核对主要转折、人物选择和停止点；方案只属于自查。独立审读在正文完成后进行，不把方案自查说成成稿审读。

## 3. 成稿与主代理自查

先加载 writing-style-contract。按人物卡和节拍成稿，保持人物声音、关系、事实与视角一致；对白保留自然交流，日常细节不必后续兑现。停留、等待、观察都可以占用篇幅，不把慢节奏写成更多紧张的小动作。

正文到指定停止点停止，不追加前史、后日谈、关系定论或完整故事闭环。局部修改只处理授权范围；若需要联动范围外的文本，说明依赖，不擅自修改或读取。

完成初稿后回读正文，核对作者要求，运行 `story_wordcount` 实测字数，按需用 `story_bible` 核对卡片字段。`story_lint` 只在自查和修订时定位字面线索，**它的命中不构成违规，也不进审读流程**。单点近似目标默认允许约 ±15% 浮动；给定区间优先落在区间内，明确的最低、最高或精确字数按硬约束处理。超出柔性目标时先判断内容是否完整，不为凑数字机械增删；说明实际字数即可。工具检查不能替代需要的独立审读。

## 4. 独立审读与修订

准备派发时读取[审读面板](review-panel.md)的角色表与派发、复核章节；不必为写作前准备完整预读。

**一次会话新建的审读子代理不超过 6 位**（B2 一位、B1 一位、B3/B4/B5 合计最多三位、最终盲读一位）。所以本节所有"派"的动作，除第一次之外都是 `send_message` 回原读者：

- **所有独立审读都在完稿之后**：B1 冷读、B2 逻辑审读、B3/B4/B5 按条件派，读的都是已经落地的正文；**关系轴（§4.0）不是另一次派发，它就是 B2 那一轮的一部分**。
- 方案阶段不派读者（见 §2）：那时没有正文，判不出"这一跳有没有支点"；方案的必答项由主代理自查，自查不算独立审读。
- B1/B2 审新稿和实质性改写；后续只有改动影响原报告的实质问题或对应风险时才复核。B3/B4/B5 按受影响维度派给已在场读者。
- 读者只在改动大到等于重写（场景顺序、结局、视角换了）时才弃用；最终盲读是唯一一次按需新建。

派发前先看 `list_agents` 确认读者是否在场；额度接近上限时先复用、再借用边界允许的读者，最后才标待审。**不要为了"再来一轮独立意见"反复新建**——那既占名额，也是每位读者从头重读一遍全文。

### 4.0 关系轴审读

正文涉及重要关系转折时，B2 在常规逻辑审读中一并核对转折前的文本依据；没有关系线就跳过这一项。合理推断、含混感情和开篇前形成的关系可以成立，不强制起点场景或“不可否认”的露出。只有转折让读者难以跟上时，才引用原文报告缺口。

首次成稿后与 B2 常规轮次同派。后续实质修改了关系状态、人物动机或关键转折时交原 B2 复核；纯措辞、标点小改不重跑。

### 常规轮次

- **谁在什么时候派，以面板的角色表为准**：B1 与 B2 审新稿、续写正文和实质性改写；B3、B4、B5 按具体风险派。复核在场读者用 `send_message`，不为每次改动新建读者。
- 五个角色各有一个专用工具（`subagent_review_b1` … `subagent_review_b5`）。人设、阅读边界、报告格式与只读限制已经装在角色身上，派发时**只给变量**：正文路径、待审版本、交付形态与范围、阅读模式、按角色需要的材料路径。不要再从面板抄模板，也不要再写“不许改文件”这类请求——`toolFilter` 已经在权限层剥掉了写入与再委派。
- 审读员用后台派发（省略 `run_in_background`），**不要传 `run_in_background: false`**：前台调用拿不到可复用的 childId。记住每个角色的 childId；派发到回收期间暂停修改被读的版本。
- 收到报告后主代理修订，相关问题交**原读者**复核：`send_message` 发回同一个 childId，附新版号、实际改动和它自己的旧条目。想不起 id 时用 `list_agents` 按 description 找回。只有**最终盲读**另起一位全新读者。
- 后续修改影响重要的动作、位置或物品状态链时，交原 B5 复核相关范围；B5 必要复核缺失时保持待审。
- 一句或一段的措辞、标点润色由主代理回读改动与接缝，无需独立读者。若这一句改变因果、动机、设定、视角或物理状态，派对应角色；重写整个场景按实质性改写处理。
- 只要方案：主代理按规模自查人物、节拍和停止点，交付方案，不自动写正文。只要评价：按作者的问题派对应角色，物理与空间问题交 B5，不自动改稿。
- 作者或读者说“我没看懂”时，先定位具体困惑，检查信息顺序、必要依据和有意留白，再决定是局部澄清还是结构改写；不预设必须补一拍。

把报告分为事实矛盾、理解障碍、范围或字数偏离、人物与节拍问题、阅读体验和口味建议，逐项处理。不要求照单全改；不采纳要有依据。读者要求片段交代后续、为普通物件回收伏笔，不能仅凭该意见扩大正文范围。独立审读不可用时，交付状态保持待审并说明实际错误，不能自行宣布通过。

## 5. 连载与版本

连载读者可以按顺序读获准的已发布前文正文，但 B1 仍不读人物卡、节拍和作者摘要。不得越过目录限制去找前文；材料不足就报告检查边界。B2 才读取相关卡片、节拍、时间线或术语表。

每次派发记录路径与正文内容版本，报告返回时核对版本。改稿以原文短引定位，不把不同版本的段落号直接比较。最终审读后再实质修改正文，要复验相关范围，不能把旧报告当作新版验收。

## 6. 交付

较长项目检查相关人物卡和节拍是否与实际正文相容，必要时更新受影响记录。完成本次所需的独立审读与复核后，简短交付稿件路径、实测字数和审读状态；纯文字小改说明已自查即可。

有未完成的读取、规划或审读步骤时如实列明，稿件标为待审，不声称流程完成。作者明确取消某项工作时遵从并说明；“片段”“快写”“角色自拟”本身不构成取消。正文无需写完整部故事，但本次约定范围的创作与审读要做完。
