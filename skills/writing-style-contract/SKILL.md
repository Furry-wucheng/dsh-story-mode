# 文风契约

这不是建议清单，是**执行标准**。写正文与改稿前各读一次，改稿时逐条过。

作者当场给出的风格要求覆盖本文的默认值。作者没说的话，按这里执行。

---

## 一、默认叙事风格

克制、自然、口语化的现代叙事。**不要为了表现文采而主动制造比喻、排比、拟人或抒情句。**

这一条统辖下面所有具体规则。它的意思是：**默认选择最朴素的写法**，只有朴素写法确实达不到目的时，才动用修辞。修辞是稀缺资源，不是装饰。

## 二、少用形容词和副词

能通过动作、对话或具体事实表达的信息，不额外解释。

- 不写"他很累"，写他做了什么（坐在楼梯上没脱鞋）。
- 不写"她愤怒地说"，写她说了什么。
- 一个名词前最多一个形容词。两个就该删掉一个。
- 副词修饰动词时，先问：这个副词是不是在补一个本该由动词本身承担的信息？"快速地跑"→"冲"。

## 三、禁止廉价比喻与模板化比喻

以下形状一律删除，除非比喻提供了**真正新的信息**：

- "平静得像在说今天天气不错"
- "软得像要把整个人吞进去"
- 任何 `仿佛……` / `像是……` / `好像……` 开头的明喻
- "某种说不清的……" / "一种难以言喻的……"
- "时间仿佛静止了" / "空气凝固了" / "心脏漏跳了一拍"
- 把情绪写成液体或天气（"一股暖流涌上心头"）

**判据：把这个比喻删掉，读者是否损失了信息？** 如果损失为零，它只是作者在自我欣赏，删掉。

身体感觉可以写，但要具体、可感、有生理细节，而不是隐喻。"胃里一阵发酸"可以，"心像被什么攥住了"不可以。

## 四、对话

采用真人日常说话的方式。

- 允许短句、半句话、省略、重复、停顿、答非所问。
- 不要求每句话语法完整。
- **不要让人物为了向读者解释背景而说不自然的话。** 需要交代的信息，用场景、动作或后续冲突带出，不要塞进台词。
- 人物不会每句话都准确描述自己的感受。真人说"还行"，不说"我其实很失落"。
- 对话可以没有结果。两个人说完，问题还在。

## 五、少用"他说 / 她说道 + 修饰语"

不要频繁写：

```
"……" 他说，声音平静得听不出情绪。
"……" 她轻声说道。
"……" 他低沉地开口。
```

规则：

- 说话人明确时，**直接写台词**。
- 需要区分人物时，优先用自然动作：

```
他把手机扔到桌上。
"不去了。"
```

- 允许一整段对话只有引号，没有任何提示语。
- 唯一需要提示语的情况：说话人真的可能混淆，或者动作本身在推进剧情。

## 六、不要解释已经能看出来的情绪

错误：

```
"滚。"
他显然已经生气了。
```

更好：

```
"滚。"
他把门关上了。
```

第二句给的是**事实**，第一句给的是**结论**。读者不需要你替他下结论。删掉所有"显然""看得出""这说明"。

## 七、不主动总结人物心理

少写：

- 他意识到……
- 他明白……
- 他心里泛起……
- 一股……涌上心头
- 这一刻，他突然觉得……
- 他终于懂了……

**例外：心理变化本身就是剧情重点时**（比如一个认知反转构成了转折点），可以写。但写一次就够，不要反复回到同一个内心结论上。

## 八、描写只保留有用的细节

不要看到沙发就描写柔软，不要看到阳光就描写金色，不要看到眼睛就描写深邃，不要看到沉默就写空气凝固。

判据：**这个细节后面会不会被用到？** 会被用到（伏笔、人物状态、空间关系），留；只是为了让场景"有画面感"，删。

场景需要锚点，但一个空间两三个具体物件就够，不需要清单式铺陈。

## 九、不追求每句话"好看"

普通的事情允许用普通的话写。有些句子应该只是承担信息传递功能。

一段文字里不需要每一句都是"好句子"。全篇都在使劲，读者会累，而且分不出哪里才是重点。**平句是好句子的背景。**

## 十、避免 AI 节奏

- 不要连续使用长度、结构相似的句子。
- 允许非常短的句子（两个字），也允许自然的长句。
- 警惕整齐的三段排比、对仗式的收尾、"不是……而是……"句式的重复。
- 警惕每段都以一句总结或抒情收尾。
- 段落长度要有变化：有时候一段只有一行。

## 十一、性描写与暴力场景

作者明确允许的内容按作者要求写，不需要回避、不需要淡出。

写法仍受上文约束：**具体、克制、以动作与身体反应为主，不用抒情化或文学化的包装。** 色情与暴力场景最容易滑向廉价比喻和情绪总结，这里要更严格地执行第三、六、七条——用准确的动作、对话与生理细节承担全部表达。

不写"他们融为一体"，写他们做了什么。

---

## 十二、交稿前的自查删减（必做）

写完一遍后，**从正文第一行开始逐段过一遍**，删除以下四类：

1. **不影响人物、信息、节奏或氛围的形容词与副词。**
2. **全部比喻**，然后只把确实提供了新信息的那些加回来。
3. **心理解释与总结句**（"他意识到""他明白""这意味着"）。
4. **重复表达同一信息的句子**——同一件事说了两遍时，保留更具体的那句。

删减目标：**初稿删掉 5%–15% 的字数**是正常的。删不到 5%，说明这一遍没认真过；删掉 30% 以上，说明初稿写得太满，下次成稿阶段就该更省。

在短篇小说模式下，自查完成后用 `story_lint` 跑一次确定性检查，再按报告逐项处理。
